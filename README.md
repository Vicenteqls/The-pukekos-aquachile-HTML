## 📌 Descripción del Proyecto
Este proyecto consiste en el desarrollo de un **MVP (Producto Mínimo Viable) Web Full Stack** diseñado para digitalizar, centralizar y hacer seguimiento al proceso administrativo de **evaluaciones psicolaborales** en la empresa **AquaChile**[cite: 1].

El sistema permite registrar datos de candidatos ficticios, generar solicitudes de evaluación, asignar responsables, actualizar el flujo de estados (*Pendiente*, *En proceso*, *Finalizada*), cargar resultados y visualizar indicadores en un dashboard consolidado[cite: 1].

> ⚠️ **Declaración de Privacidad y Alcance Académico:**  
> Este prototipo utiliza exclusivamente **datos simulados, ficticios o anonimizados**[cite: 1]. No requiere ni almacena información personal sensible, documentos reales ni credenciales de sistemas corporativos de AquaChile[cite: 1].

## ⚙️ Roles Definidos en la Aplicación

1. **Analista de Reclutamiento:** Inscribe candidatos ficticios, genera solicitudes de evaluación y realiza búsquedas/filtros por estado o cargo[cite: 1].
2. **Profesional Evaluador:** Revisa las solicitudes asignadas, asigna la fecha de evaluación, registra observaciones clínicas/resultados y actualiza el estado[cite: 1].
3. **Jefatura / Contraparte:** Visualiza el dashboard con métricas e indicadores de avance general en modo lectura[cite: 1].
4. **Administrador Académico:** Configura catálogos de prueba, usuarios y parámetros para la demostración[cite: 1].

## 💻 Stack Tecnológico

- **Frontend:** React (JavaScript / JSX), HTML5, CSS3 / Bootstrap 5 o Tailwind CSS[cite: 1].
- **Backend:** Node.js / Express (o alternativa monolítica autorizada)[cite: 1].
- **Base de Datos:** Persistencia relacional/no-relacional para entidades (Candidatos, Solicitudes, Evaluaciones)[cite: 1].
- **API:** RESTful HTTP / JSON[cite: 1].
